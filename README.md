# Lumo

Интерпретатор учебного языка **Lumo**. Реализованы лексер, парсер рекурсивного спуска, строящий AST, и вычислитель, который выполняет AST: точка входа `main`, локальные переменные типа `int`, пользовательские функции, арифметика и ввод/вывод.

Спецификация языка: [docs/specification.md](docs/specification.md).

## Требования

.NET 10 SDK (C# 14): https://dotnet.microsoft.com/en-us/download/dotnet/10.0

## Структура проекта

| Каталог | Назначение |
|---------|------------|
| `src/Lumo.Lexing` | Модуль лексического анализа: лексер, токены, таблица ключевых слов |
| `src/Lumo.Ast` | Узлы абстрактного синтаксического дерева и интерфейс посетителя `IAstVisitor` |
| `src/Lumo.Parsing` | Парсер строит AST, семантический анализатор проверяет имена, аргументы и возвраты |
| `src/Lumo.Execution` | Вычислитель AST (`AstEvaluator`) и окружение ввода/вывода (`IEnvironment`) |
| `src/Lumo.Cli` | Консольный интерпретатор `lumo`: конвейер лексер → парсер → AST → семантический анализатор → вычислитель |
| `tests/Lumo.Cli.AcceptanceTests` | Приёмочные тесты интерпретатора: запуск программ через CLI с подменёнными потоками |
| `tests/Lumo.Lexing.UnitTests` | Модульные тесты лексического анализатора |
| `tests/Lumo.Parsing.UnitTests` | Модульные тесты парсера: форма AST, приоритет и ассоциативность операторов, позиции узлов |
| `tests/Lumo.Execution.UnitTests` | Модульные тесты вычислителя AST: арифметика, порядок вычисления, ввод, ошибки выполнения |
| `docs` | Спецификация языка |
| `examples` | Примеры программ на Lumo |

## Сборка и запуск

```bash
# Сборка
dotnet build

# Запуск тестов
dotnet test

# Запуск программы (введите 5 и нажмите Enter)
dotnet run --project src/Lumo.Cli -- examples/expressions.lumo
```

Пример выводит `11`, `1`, `-3`, `-1` — по одному числу в строке.
Интерпретатор сначала разбирает программу и строит AST, проверяет его семантику, затем вычислитель выполняет дерево.
Выполнение начинается только после успешного разбора и семантической проверки, поэтому ошибки компиляции
обнаруживаются до первого ввода и вывода, как требует спецификация.
Ошибка выводится в stderr, код возврата — 1. При ошибке выполнения уже сделанный вывод сохраняется.
`sample.lumo` показывает возможности следующих итераций, поэтому текущая версия интерпретатора его не выполняет.

## Пример третьей итерации

Выполните команду и введите четыре координаты по одной на строку: `5`, `-2`, `1`, `3`.
Программа вызывает пользовательскую функцию и выводит площадь прямоугольника: `20`.

```bash
dotnet run --project src/Lumo.Cli -- tests/Lumo.Cli.AcceptanceTests/Programs/rectangle_area.lumo
```

Программа `scopes_and_functions.lumo` в том же каталоге показывает затенение имён, присваивание внешней
переменной из вложенного блока, `return` из вложенного блока и общее имя у переменной и функции.
Она не читает ввод и выводит: `20`, `10`, `23`, `1`, `30`, `2`, `23` — по одному числу в строке.
