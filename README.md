# Lumo

Интерпретатор учебного языка **Lumo**. Реализованы лексер и парсер рекурсивного спуска без AST: точка входа `main`, целочисленные выражения и ввод/вывод.

Спецификация языка: [docs/specification.md](docs/specification.md).

## Требования

.NET 10 SDK (C# 14): https://dotnet.microsoft.com/en-us/download/dotnet/10.0

## Структура проекта

| Каталог | Назначение |
|---------|------------|
| `src/Lumo.Lexing` | Модуль лексического анализа: лексер, токены, таблица ключевых слов |
| `src/Lumo.Parsing` | Разбор грамматики, проверка программы и выполнение |
| `src/Lumo.Cli` | Консольный интерпретатор `lumo` |
| `tests/Lumo.Parsing.IntegrationTests` | Интеграционные тесты интерпретатора: запуск программ через CLI с подменёнными потоками |
| `tests/Lumo.Lexing.UnitTests` | Модульные тесты лексического анализатора |
| `docs` | Спецификация языка |
| `examples` | Примеры программ на Lumo |

## Сборка и запуск

```bash
# Сборка
dotnet build

# Запуск тестов
dotnet test

# Запуск программы (введите 5 и нажмите Enter)
dotnet run --project src/Lumo.Cli -- examples/expressions.lumo
```

Пример выводит `11`, `1`, `-3`, `-1` — по одному числу в строке.
Интерпретатор сначала проверяет всю программу, затем повторно разбирает её с выполнением.
Проверочный проход не читает stdin и не пишет stdout; AST не строится. Это сохраняет
требование спецификации обнаруживать ошибки компиляции до начала выполнения.
Ошибка выводится в stderr, код возврата — 1. При ошибке выполнения уже сделанный вывод сохраняется.
`sample.lumo` показывает возможности следующих итераций, поэтому текущая версия интерпретатора его не выполняет.
