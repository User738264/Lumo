# Lumo

Интерпретатор учебного языка **Lumo**. Реализованы лексер, парсер рекурсивного спуска, строящий AST, и вычислитель, который выполняет AST: точка входа `main`, целочисленные выражения и ввод/вывод.

Спецификация языка: [docs/specification.md](docs/specification.md).

## Требования

.NET 10 SDK (C# 14): https://dotnet.microsoft.com/en-us/download/dotnet/10.0

## Структура проекта

| Каталог | Назначение |
|---------|------------|
| `src/Lumo.Lexing` | Модуль лексического анализа: лексер, токены, таблица ключевых слов |
| `src/Lumo.Ast` | Узлы абстрактного синтаксического дерева и интерфейс посетителя `IAstVisitor` |
| `src/Lumo.Parsing` | Парсер: строит AST и находит ошибки компиляции |
| `src/Lumo.Execution` | Вычислитель AST (`AstEvaluator`) и окружение ввода/вывода (`IEnvironment`) |
| `src/Lumo.Cli` | Консольный интерпретатор `lumo`: конвейер лексер → парсер → AST → вычислитель |
| `tests/Lumo.Parsing.IntegrationTests` | Интеграционные тесты интерпретатора: запуск программ через CLI с подменёнными потоками |
| `tests/Lumo.Lexing.UnitTests` | Модульные тесты лексического анализатора |
| `tests/Lumo.Parsing.UnitTests` | Модульные тесты парсера: форма AST, приоритет и ассоциативность операторов, позиции узлов |
| `tests/Lumo.Execution.UnitTests` | Модульные тесты вычислителя AST: арифметика, порядок вычисления, ввод, ошибки выполнения |
| `docs` | Спецификация языка |
| `examples` | Примеры программ на Lumo |

## Сборка и запуск

```bash
# Сборка
dotnet build

# Запуск тестов
dotnet test

# Запуск программы (введите 5 и нажмите Enter)
dotnet run --project src/Lumo.Cli -- examples/expressions.lumo
```

Пример выводит `11`, `1`, `-3`, `-1` — по одному числу в строке.
Интерпретатор сначала разбирает всю программу и строит AST, затем вычислитель выполняет дерево.
Выполнение начинается только после успешного разбора, поэтому ошибки компиляции
обнаруживаются до первого ввода и вывода, как требует спецификация.
Ошибка выводится в stderr, код возврата — 1. При ошибке выполнения уже сделанный вывод сохраняется.
`sample.lumo` показывает возможности следующих итераций, поэтому текущая версия интерпретатора его не выполняет.
