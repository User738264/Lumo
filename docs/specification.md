# Спецификация языка Lumo

## Введение

**Lumo** — минималистичный императивный язык программирования общего назначения
со строгой статической типизацией и явным объявлением переменных.

Ключевые особенности языка:

- программа целиком располагается в одном файле;
- точкой входа является функция `main`, вызываемая при запуске программы;
- строгая статическая типизация: встроенные типы `int` (64-битные знаковые
  целые числа), `string` (строки) и `bool` (логический тип);
- императивный, процедурный стиль программирования;
- арифметические (`+ - * / %`), логические (`&& || !`) и операторы
  сравнения (`== != < <= > >=`);
- ввод/вывод осуществляется через встроенные функции `print_int`,
  `print_string`, `print_bool`, `read_int`, `read_string`;
- переменные объявляются явно с указанием типа;
- поддержка структурного программирования: ветвление `if`/`else`, цикл
  `while` с инструкциями `break` и `continue`, последовательное выполнение
  инструкций в блоке;
- поддержка массивов фиксированного размера;
- поддержка структур (записей) для группировки данных.

Синтаксис Lumo близок к языкам семейства C (блоки в фигурных скобках,
инструкции разделяются точкой с запятой), при этом объявление переменных
использует форму `имя: тип`, как в Pascal и TypeScript. Структуры по
устройству близки к структурам C и Go — это простые записи без методов,
что соответствует процедурному стилю языка.

## Лексика

Раздел описывает лексические единицы (токены) языка Lumo и правила их
выделения из текста программы.

### Нотация

Правила записаны в БНФ со следующими соглашениями: `::=` — определение
правила, `|` — выбор одной из альтернатив, `X*` — ноль или более повторений
`X`, `"a".."z"` — любой символ указанного диапазона, круглые скобки —
группировка, символы в кавычках — литеральные последовательности.

### Кодировка

Исходный код — текст в кодировке UTF-8. Идентификаторы и ключевые слова
состоят только из латинских букв, цифр и символа подчёркивания.
Строковые литералы могут содержать произвольные символы Unicode.

### Пробельные символы

Пробельные символы разделяют токены и в остальном не имеют значения: их
количество и чередование не влияют на смысл программы.

| Символ                        | Обозначение | Код  |
|-------------------------------|-------------|------|
| Пробел                        | SP          | 0x20 |
| Горизонтальная табуляция      | HT          | 0x09 |
| Перевод строки                | LF          | 0x0A |
| Возврат каретки               | CR          | 0x0D |

Конец строки записывается как одиночный LF (`\n`), как пара CR LF
(`\r\n`) или как одиночный CR (`\r`); пара CR LF считается одним концом
строки. При разделении токенов все три варианта равнозначны, поскольку CR
и LF являются пробельными символами по отдельности.

### Комментарии

Поддерживаются два вида комментариев, которые лексер отбрасывает и не
передаёт синтаксическому анализатору:

| Вид        | Синтаксис      | Пример               |
|------------|----------------|----------------------|
| Строчный   | `// текст`     | `// это комментарий` |
| Блочный    | `/* текст */`  | `/* блок */`         |

Строчный комментарий заканчивается ближайшим концом строки или концом
файла. Блочные комментарии не поддерживают вложенность: первая
встретившаяся последовательность `*/` завершает комментарий.

### Идентификаторы

```
identifier ::= (letter | "_") (letter | digit | "_")*
letter     ::= "a".."z" | "A".."Z"
digit      ::= "0".."9"
```

Идентификатор начинается с латинской буквы или символа подчёркивания и
может содержать латинские буквы, цифры и символы подчёркивания.
Идентификаторы чувствительны к регистру (`sum` и `Sum` — разные имена).
Идентификатор не может совпадать с ключевым словом.

### Ключевые слова

Зарезервированы и не могут использоваться как идентификаторы:

```
var func return if else while break continue struct
true false int string bool
```

### Предопределённые идентификаторы

Имя `main` ключевым словом не является — это обычный идентификатор,
который по соглашению обозначает функцию — точку входа в программу.

Имена встроенных функций ввода/вывода `print_int`, `print_string`,
`print_bool`, `read_int`, `read_string` также не являются ключевыми
словами: лексер выделяет их как обычные идентификаторы, а их особый
смысл определяется на этапе семантического анализа.

### Литералы

**Целочисленные литералы** (тип `int`) — последовательность десятичных
цифр без ведущих нулей (кроме литерала `0`); знак числа не входит в
литерал и обрабатывается как унарный оператор `-`.

```
int_literal ::= "0" | (("1".."9") digit*)
```

Значение литерала не должно превышать `9223372036854775807` —
максимальное значение 64-битного знакового целого. Как следствие,
минимальное значение типа `int` не может быть записано литералом
напрямую.

Сразу за целочисленным литералом не может следовать буква или символ
подчёркивания: запись `12abc` или `1_000` является ошибкой. Чтобы
разделить число и идентификатор, между ними ставится пробельный символ
или другой токен.

Примеры: `0`, `7`, `1200`.

**Строковые литералы** (тип `string`) — последовательность символов в
двойных кавычках. Поддерживаются escape-последовательности:

| Последовательность | Символ                     |
|--------------------|----------------------------|
| `\n`               | Перевод строки (LF)        |
| `\r`               | Возврат каретки (CR)       |
| `\t`               | Горизонтальная табуляция   |
| `\"`               | Двойная кавычка            |
| `\\`               | Обратная косая черта       |

Символы LF и CR внутри литерала без экранирования недопустимы, остальные
символы записываются как есть. Таким образом, литералом можно задать любой
текст, включая кавычки и переносы строк в любом формате.

```
string_literal ::= '"' (escape | string_char)* '"'
escape         ::= '\' ("n" | "r" | "t" | '"' | '\')
string_char    ::= любой символ, кроме '"', '\', LF и CR
```

Примеры: `"hello"`, `"строка\nс переносом"`, `"windows\r\n"`.

**Булевы литералы** (тип `bool`) — ключевые слова `true` и `false`.
Лексер выделяет их как ключевые слова; значением литерала они становятся
в контексте выражения.

### Операторы и знаки пунктуации

| Категория      | Токены                            |
|----------------|-----------------------------------|
| Арифметические | `+`  `-`  `*`  `/`  `%`           |
| Сравнения      | `==`  `!=`  `<`  `<=`  `>`  `>=`  |
| Логические     | `&&`  `\|\|`  `!`                 |
| Присваивание   | `=`                               |
| Доступ/индекс  | `.`  `[`  `]`                     |
| Группировка    | `(`  `)`  `{`  `}`                |
| Разделители    | `,`  `;`  `:`                     |
| Тип возврата   | `->`                              |

Символы `&` и `|` по отдельности токенами не являются и допустимы только
в составе `&&` и `||`.

### Конец файла

По достижении конца входного текста лексер выдаёт специальный токен
`end_of_file`, который используется синтаксическим анализатором как
признак завершения программы.

### Правило разбора токенов

Лексер использует принцип «максимального захвата» (maximal munch): на
каждом шаге выбирается самая длинная последовательность символов,
образующая допустимый токен. Следствия:

- `==` распознаётся как один токен сравнения, а не как два токена `=`;
- `->` распознаётся как один токен, а не как `-` и `>`;
- `//` и `/*` распознаются как начало комментария раньше, чем одиночный
  `/` — как оператор деления;
- `iffy` — это один идентификатор, а не ключевое слово `if` и
  идентификатор `fy`; ключевым словом считается только последовательность,
  совпадающая с ним целиком.

### Лексические ошибки

Следующие ситуации приводят к ошибке на этапе лексического анализа:

1. Символ, не входящий ни в один токен и встреченный вне комментария и
   строкового литерала (например, `@`, `#`, `$`, `~`, одиночный `&` или `|`).
2. Незакрытый строковый литерал: до закрывающей кавычки встретился конец
   строки или конец файла.
3. Неизвестная escape-последовательность в строковом литерале
   (например, `"\q"`).
4. Незакрытый блочный комментарий: до последовательности `*/` встретился
   конец файла.
5. Целочисленный литерал с ведущим нулём (например, `007`).
6. Целочисленный литерал, значение которого выходит за допустимый диапазон.
7. Буква или символ подчёркивания сразу после целочисленного литерала
   (например, `12abc`).
